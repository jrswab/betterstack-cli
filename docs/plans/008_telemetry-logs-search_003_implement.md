## Section 1: Context Summary

Milestone 003 adds read-only source list and get commands to the standard-library CLI. Keep the production Telemetry REST host fixed, preserve `runWithAPI` and existing Uptime routing, and use `runWithEndpoints` to test Telemetry REST routing at a real loopback request boundary. Both commands use only `BETTERSTACK_TELEMETRY_API_TOKEN` and the shared `doMonitorsRequest` GET contract. Validate arguments before reporting a missing token, preserve source response bytes on both output channels, and warn that source output includes a secret credential without claiming what the credential permits. Do not add source pagination loops, SQL behavior, logs commands, endpoint overrides, or redaction.

**Implementation assumptions:** Add source handlers and parsers in `cmd/bs/sources.go`, with `sourcesList`, `sourcesGet`, `parseSourcesListArgs`, and `parseSourcesGetArgs`. Add their tests in `cmd/bs/sources_test.go`. Add a Telemetry token environment-name constant at the source configuration boundary in `cmd/bs/sources.go`, and use the existing Telemetry REST base constant. Reuse the established `telemetry:command-handler` anchor role for source command boundaries. These names and file placement are checklist assumptions that keep the implementation surface explicit; preserve the spec's behavior if implementation needs a different private helper layout.
