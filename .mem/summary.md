# System summary

`bs` is a read-only Better Stack Uptime and Telemetry CLI implemented with the Go standard library in [cmd/bs](../cmd/bs/main.go). `runWithAPI` preserves the Uptime injection interface and delegates to `runWithEndpoints`. The latter checks exact-match help before routing monitors list/get, incidents list/get/timeline, [sources list/get](telemetry/sources.md), and [logs search](telemetry/logs.md). Help requires no credentials or requests. Uptime commands use `BETTERSTACK_UPTIME_API_TOKEN`. Source commands use only `BETTERSTACK_TELEMETRY_API_TOKEN` and the fixed Telemetry REST host. The seven Uptime/source handlers share the Request executor (`doMonitorsRequest`), which sends one bearer-authenticated GET with a 30-second default timeout, disables redirects, and passes bodies unchanged to stdout for 2xx or stderr otherwise. `logsSearch` validates flags through the Log search query builder and passes hot or optional cold SQL, separate typed parameters, and the parsed timeout to the SQL request executor. SQL requires separate URL, username, and password configuration and sends one timed Basic-authenticated POST without redirects or retries. `redactSecrets` applies only to non-2xx SQL bodies. Source help warns that output contains a secret credential. Logs help explains the full table identifier, option-shaped query data, and missing-hot-table `--cold` guidance. Tests inject guarded loopback servers or in-memory transports and clear inherited API credentials and SQL configuration. The [memory map](mem-map.md) indexes [Uptime](uptime/summary.md), [Telemetry](telemetry/sources.md), [terminology](terminology.md), and [practices](practices.md).
