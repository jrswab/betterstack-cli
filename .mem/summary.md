# System summary

`bs` is a read-only Better Stack Uptime CLI implemented with the Go standard library in [cmd/bs](../cmd/bs/main.go). `runWithAPI` preserves the existing Uptime injection interface and delegates to `runWithEndpoints`. `runWithEndpoints` routes monitors list/get and incidents list/get/timeline, or returns exact-match help without reading credentials or sending requests. It accepts separate Telemetry REST and SQL test endpoint inputs, but no Telemetry route is active. Valid commands use `BETTERSTACK_UPTIME_API_TOKEN` and the shared Request executor (`doMonitorsRequest`). The Request executor sends a bearer-authenticated GET, applies a 30-second default timeout, disables redirects, and passes response bodies unchanged to stdout for 2xx or stderr otherwise. Tests inject loopback servers and clear inherited credentials. `redactSecrets` provides direct literal Telemetry secret redaction but has no response-path caller. The [memory map](mem-map.md) indexes the [Uptime topics](uptime/summary.md), [terminology](terminology.md), and [practices](practices.md).
