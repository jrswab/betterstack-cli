# System summary

`bs` is a read-only Better Stack Uptime and Telemetry CLI implemented with the Go standard library in [cmd/bs](../cmd/bs/main.go). `runWithAPI` preserves the Uptime injection interface and delegates to `runWithEndpoints`. The latter routes monitors list/get, incidents list/get/timeline, and [sources list/get](telemetry/sources.md), or returns exact-match help without credentials or requests. Uptime commands use `BETTERSTACK_UPTIME_API_TOKEN`. Source commands use only `BETTERSTACK_TELEMETRY_API_TOKEN` and the fixed Telemetry REST host. The SQL test endpoint input has no active route. The [Log search query builder](telemetry/logs.md) validates search flags and returns hot or optional cold SQL with separate typed parameters. The SQL executor consumes prepared SQL through the optional `runWithEndpoints` input, without a logs command route. It requires separate SQL configuration and sends one timed Basic-authenticated POST without redirects. Other command behavior stays unchanged. All seven handlers use the Request executor (`doMonitorsRequest`), which sends one bearer-authenticated GET with a 30-second default timeout, disables redirects, and passes bodies unchanged to stdout for 2xx or stderr otherwise. Source help warns that output contains a secret credential. Tests inject loopback servers and clear inherited API credentials. `redactSecrets` applies only to non-2xx SQL bodies. The [memory map](mem-map.md) indexes [Uptime](uptime/summary.md), [Telemetry](telemetry/sources.md), [terminology](terminology.md), and [practices](practices.md).
